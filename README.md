# 다리 건너기

## 🚀 기능 구현 목록

### 1. 입출력 (View)
- [ ] **입력**
  - [X] 다리 길이
  - [ ] 이동할 칸 선택 (위 또는 아래 / U or D)
  - [ ] 재시작/종료 여부 입력 (R/Q)
- [ ] **출력**
  - [ ] 게임 시작 문구
  - [ ] 다리 이동 시마다
  - [ ] 최종 게임 결과

### 2. 비즈니스 로직 (Domain)
- [ ] **핵심 객체 Bridge**
  - [ ] field: 다리 길이, 건널 수 있는 칸 정보
  - [ ] method: 건널 수 있는 칸 초기화 메소드 (최초 1번)
- [ ] **부가 객체 BridgeOption**
  - [ ] 업다운 Enum
  - [ ] method: 건너는 다리가 맞는지 검증
- [ ] **관리 객체 BridgeMaker**
  - [ ] 최초 랜덤 다리
- [ ] **관리 객체 BridgeGame**
  - [ ] 이동
  - [ ] 재시작

### 3. 예외 처리 (Exception)
> 모든 예외는 `IllegalArgumentException`을 발생시키며, `[ERROR]`로 시작하는 메시지를 출력한다.

- [ ] **입력 유효성 검증**
  - [X] [예외] 다리 길이가 3~20 범위가 아니면 예외처리 (Validator/parseBridgeLength)
  - [ ] [예외] 이동 칸 입력이 U 또는 D가 아니면 예외처리 (Validator/validateIsOption)
- [ ] **비즈니스 규칙 검증**
  - [ ] [예외]
